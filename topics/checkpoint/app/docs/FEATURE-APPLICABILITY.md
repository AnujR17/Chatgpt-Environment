# Current feature applicability

The current implementation and limits are documented in [Pip companion](PIP-COMPANION.md) and [video/model research](VIDEO-AND-MODEL-RESEARCH.md). Face movements, experimental HSEmotion categories, a frameless desktop companion, local read-only phone dashboard, numeric game-focused input aggregation and report export are implemented. No full-game event recognizer, validated frustration/mood estimator, automatic CMA, microphone capture, universal fullscreen compatibility or measured intervention benefit is claimed.

[Windows instructions](WINDOWS-APP.md). Current release evidence is separate from historic model/card tests.
