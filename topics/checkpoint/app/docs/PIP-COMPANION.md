# Nori companion

The character previously named Pip is now Nori. Current controls and evidence are documented in [Nori reflection and CMA](NORI-REFLECTION-AND-CMA.md).

Reflection is the default. Face preview is the immediate mirror/tester. Choose a feeling for a confirmed check-in, enable Show Nori for the frameless overlay, and hold Ctrl+Alt to drag it. Phone dashboard pairs locally; desktop and phone export CMA PDFs. See [updates](IN-APP-UPDATES.md) and [camera/phone help](CAMERA-AND-PHONE-TROUBLESHOOTING.md).
