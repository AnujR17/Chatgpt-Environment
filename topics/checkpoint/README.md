# Regen

A native Windows gaming companion with Nori, play reminders and CMA check-ins.

**[Download the Windows app](https://github.com/AnujR17/Chatgpt-Environment/releases/download/checkpoint-v0.6.4-preview.1/Checkpoint-Windows-Preview.zip)**

Extract the complete ZIP and run Checkpoint-Windows/Start Checkpoint.cmd. Turn on Break reminders for a thought-cloud prompt after 30 seconds. Adjust the interval in Session or Settings. Setback support and game observation are separate options.

Existing installations: Settings > Check for updates > Update and restart.
