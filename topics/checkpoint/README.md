# Checkpoint with Nori

The Windows app, transparent Nori desktop companion and local phone dashboard live on **topic/checkpoint**.

**[Download the Windows app](https://github.com/AnujR17/Chatgpt-Environment/releases/download/checkpoint-v0.4.0-preview.2/Checkpoint-Windows-Preview.zip)** — extract the entire ZIP and run Start Checkpoint.cmd.

[App, screenshots and pairing](app/README.md) · [Model/video research](app/docs/VIDEO-AND-MODEL-RESEARCH.md) · [Source list CSV](app/design/gameplay-video-shortlist.csv) · [Verification](RELEASE-VERIFICATION.json)

Research persona interviews remain simulated. No real participant studies or validated gamer frustration detection are claimed.

Current default is a sustained Reflection; Face preview is the instant tester. Report exports a CMA PDF from check-ins, with separately labelled aggregate visual context. See app/docs/NORI-REFLECTION-AND-CMA.md. Existing 0.3 users can use Settings → Check for updates.
