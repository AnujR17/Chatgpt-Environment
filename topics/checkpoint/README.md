# Regen

A native Windows gaming companion with Nori, play reminders and CMA check-ins.

**[Download the Windows app](https://github.com/AnujR17/Chatgpt-Environment/releases/download/checkpoint-v0.6.2-preview.1/Checkpoint-Windows-Preview.zip)**

Extract the complete ZIP and run Checkpoint-Windows/Start Checkpoint.cmd. In the app, choose Start play support, then switch to the game. Nori offers a short reminder after about 2½ minutes of active play, with support after possible falls in Getting Over It.

Existing installations: Settings > Check for updates > Update and restart.
