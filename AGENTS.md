# Job-search routing

For personal job-search work, use the existing `topics/job-search-agent/app`
on branch `topic/job-search-agent`. Read the topic handoff and
`.agents/skills/job-search-agent/SKILL.md`. Preserve public research IDs and
browser-local profile, notes, stages, blacklist and assessments.

The separate `topic/ai-job-search` starter is a historical prototype. Apply
useful ideas to the existing board rather than creating another tracker.
Private requests, returned documents, CVs and backups must stay outside Git.
Use `topics/job-search-agent/private/` for files processed in this workspace.
